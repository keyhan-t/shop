# Bloom — E-commerce Website

A modern e-commerce website UI built with React and Vite.

Bloom is a fictional online shopping project created to practice and demonstrate frontend development skills. The project focuses on building a clean shopping experience with reusable React components and a structured interface.

## Features

- Product-focused shopping interface
- Reusable React components
- Navigation bar and footer
- Product cards and product listings
- Hero section and promotional content
- Responsive layout
- Interactive UI elements and animations

## Tech Stack

- React
- JavaScript
- Vite
- HTML5
- CSS3

## Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have Node.js and npm installed.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/keyhan-t/shop.git
   ```

2. Navigate to the project directory:

   ```bash
   cd shop
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.

## Build

To create a production build:

```bash
npm run build
```

The generated files will be available in the `dist` directory.
